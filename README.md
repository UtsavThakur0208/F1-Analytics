# 🏎️ Formula 1 Performance Analytics Dashboard

## 📌 Project Overview

This project analyzes historical Formula 1 race data to uncover insights into driver performance, constructor dominance, race outcomes, and pit stop strategies.

The goal is to build a complete data analytics pipeline—from raw data cleaning and preprocessing to interactive visualizations and dashboard development.

---

## 🎯 Objectives

* Clean and preprocess Formula 1 datasets
* Merge multiple data sources into a master analytical dataset
* Perform exploratory data analysis (EDA)
* Analyze driver and constructor performance
* Study positions gained/lost during races
* Evaluate pit stop strategies and efficiency
* Build an interactive dashboard for data-driven insights

---

## 📂 Dataset

The project uses historical Formula 1 datasets containing:

* Race Results
* Drivers
* Constructors
* Circuits
* Race Information
* Pit Stops
* Lap Times
